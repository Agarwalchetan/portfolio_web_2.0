# Agarwal Chetan's Portfolio Web 2.0

A modern, responsive personal portfolio website built using **React (TypeScript)**, **Tailwind CSS**, and **Vite**. This portfolio showcases projects, achievements, and skills in a clean and structured UI.

## 🚀 Features

* **Hero Section** with intro, current focus, and social links
* **Projects Section** with project cards
* **Blog/Achievements Section** showcasing certificates and timelines
* **Contact Form** with embedded Google Maps
* **Dark/Light Theme Toggle**
* Fully **Responsive Design**
* Optimized with **Vite** for fast build and dev experience

## 🧪 Installation & Setup

```bash
# Clone the repository
$ git clone https://github.com/agarwalchetan/portfolio_web_2.0.git
$ cd portfolio_web_2.0

# Install dependencies
$ npm install

# Start development server
$ npm run dev
```

---

## 📦 Build for Production

```bash
# Build the app
$ npm run build

# Preview the production build
$ npm run preview
```
